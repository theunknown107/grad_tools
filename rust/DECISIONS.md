# Rust Core migration: decisions

These come from the architecture audit and the `rust-anything analyze` plan. The raw analyzer output and the audit itself are kept outside the repository.

| #      | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Status                 | Reason                                                                                                                                                                  |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ADR-1  | Rust owns pure domain and processing logic only. TypeScript keeps UI, hooks, repositories, auth, sync, the API server and every I/O adapter: pdf.js, tesseract.js, officeparser, canvas, IndexedDB.                                                                                                                                                                                                                                                                                                                                                                         | accepted               | The analyzer marks those units `keep`; the product keeps its React shell.                                                                                               |
| ADR-2  | One bridge kind, **wasm-bindgen**, built with cargo and wasm-bindgen-cli (no wasm-pack). One crate per unit under `rust/`.                                                                                                                                                                                                                                                                                                                                                                                                                                                  | accepted               | Portable to both the browser and the Android WebView; one artifact for both.                                                                                            |
| ADR-3  | In the browser the WASM will run in a dedicated Web Worker, created lazily and terminated after use, following `lib/ocr.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                | proposed (Gate 4)      | Keeps parsing off the UI thread and memory bounded on phones; no SharedArrayBuffer needed.                                                                              |
| ADR-4  | Android uses the same WASM inside the Capacitor WebView. No JNI and no NDK.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | accepted               | The app has no Kotlin or Java logic. rust-anything's JNI runtime needs API 26; the app's minSdk is 24.                                                                  |
| ADR-5  | The first unit is `apps/web/src/domain/timetable/`. It was created by a behaviour-preserving move of `timetable-import.ts`, `docx-timetable.ts` and `lib/docx-structure.ts`. The old paths re-export, and `timetable/primitives.ts` owns `WEEKDAYS`/`Weekday`, `subjectKey` and `PositionedText` (re-exported from `types.ts`, `subjects.ts` and `pdf-layout.ts`).                                                                                                                                                                                                          | done (Gate 2)          | Before the move, `domain/` was one 11,953-line unit inside an import cycle with UI code. After it, `domain/timetable/` is a wave-0 leaf and `domain/` leaves the cycle. |
| ADR-6  | The OCR engine stays outside the core. The core will accept normalised text with boxes and the engine's own confidence. Confidence is `null` when the engine gives none, never invented.                                                                                                                                                                                                                                                                                                                                                                                    | proposed               | No cloud OCR and no Python server; the OCR model can change without touching the parser.                                                                                |
| ADR-7  | Errors cross as `Err("TypeName: message")`, which becomes a thrown JS error. Abstention (unresolved subjects, conflicts, coverage) is data, not an error. Panics never reach the UI.                                                                                                                                                                                                                                                                                                                                                                                        | accepted               | Keeps today's semantics and UI contracts.                                                                                                                               |
| ADR-8  | Rollout uses `rust-anything shadow`. TypeScript stays authoritative, Rust runs second in development, mismatches are logged locally without document text, and `RUST_ANYTHING_MODE=old` rolls back.                                                                                                                                                                                                                                                                                                                                                                         | proposed (Gate 3+)     | Shipping shadow code must not change behaviour.                                                                                                                         |
| ADR-9  | Three measurements, never merged: recorded parity (`diff`), ground-truth accuracy (the frozen research scorer, run outside the repository), and `bench`. A known parser bug is fixed only as an approved `known-diffs.jsonl` entry with a ground-truth regression case.                                                                                                                                                                                                                                                                                                     | accepted               | Parity with a buggy original is not correctness.                                                                                                                        |
| ADR-10 | No private documents, mappings, answer keys or OCR dumps in `rust/`. `cases.jsonl` and `inputs/` hold only synthetic strings and strings already present in this repository's tests.                                                                                                                                                                                                                                                                                                                                                                                        | accepted               | Privacy.                                                                                                                                                                |
| ADR-12 | Gate 3 found no justified mid-size boundary. In TypeScript the whole per-document parse costs 0.3–5.5 ms (warm median). Every smaller candidate (`readDictionary` 0.01–0.16 ms, `resolveGridSubject`, `initialismsFor`) does microseconds of work, which the 1–4 µs WASM crossing cannot beat, and is called only inside `parseTimetable`, so an in-app shadow at that level would never run. The only boundary with one crossing per document, an app caller and a meaningful ground-truth score is `parseTimetable` + `docxTimetables` as a whole (about 1,800 TS lines). | open: needs a decision | Porting the whole parse can be justified only by maintainability or shared-core reasons, not speed. The alternative is to pause the timetable migration.                |
| ADR-13 | `rust-anything.json` stores `root` as `"../.."` (crate-relative). The tool resolves a relative root against the crate folder and keeps it relative when it saves.                                                                                                                                                                                                                                                                                                                                                                                                           | accepted (Gate 3)      | No absolute local path in a repository file.                                                                                                                            |
| ADR-11 | A crate's generated build output (`target/`, `pkg/`, `.rust-anything/`) and its generated `index.cjs` are excluded from Prettier and ESLint, and each crate carries `package.json` `{"type": "commonjs"}`.                                                                                                                                                                                                                                                                                                                                                                  | accepted (Gate 2)      | The root package is `"type": "module"`, so Node would otherwise load wasm-bindgen's CommonJS output as ESM. Generated files are never hand-edited.                      |
