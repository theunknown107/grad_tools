# Rust Core migration map

**Goal:** a shared Rust domain core, compiled to WebAssembly, under the existing React app and its Capacitor WebView shell. This is not a whole-app lift: React, shadcn/ui, hooks, repositories, the API server and every I/O adapter stay in TypeScript.

**Tool:** [rust-anything](https://github.com/erkamyaman/rust-anything) 2.1.0 at commit `e795d53d8b2938205708d681ec474f07b6ab18a7`.

**Current gate:** Gate 3 is done: the WASM was validated in browsers and the Android WebView, the boundary investigation was run, and ground truth plus shadow were compared off-app. The recommendation is in `HANDOFF.md`. **Gate 4 waits for a decision** on the parse boundary (DECISIONS ADR-12).

Read next: [HANDOFF.md](HANDOFF.md) · [DECISIONS.md](DECISIONS.md) · [GLOSSARY.md](GLOSSARY.md) · [PORT_MAP.md](PORT_MAP.md) (generated by `rust-anything map --write`; the measured state)

None open. Slice 1 of unit 1 was done on 2026-11-20 (Gate 2).

## Out of scope until separately approved

- In-app PaddleOCR or any OCR model runtime
- JNI or the Android NDK (the WebView runs the same WASM)
- Shadow mode or a production cutover
- Snyk Code
- Kotlin dependency changes
- The express-rate-limit 8 upgrade
