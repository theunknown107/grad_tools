# Glossary: GradTools terms and their Rust names

The Rust names follow **existing GradTools types** (from `domain/timetable-import.ts`, `docx-timetable.ts`, `lib/docx-structure.ts` and `ocr-layout.ts`). Where the brief suggested a different name, the existing name wins and the brief's term appears in the last column.

| GradTools (TS)                             | Rust                                                                                                                  | Meaning                                                                                               | Brief's term                                                          |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `ParsedTimetable`                          | `ParsedTimetable`                                                                                                     | The parse result: slots, classes, dictionary, context, conflicts, coverage                            | Timetable                                                             |
| `GridClass`                                | `GridClass`                                                                                                           | One class read from the grid: day, start, end, initials, room, batch, subject code, resolution, spans | Class entry (`ClassEntry`)                                            |
| `TimeSlot`                                 | `TimeSlot`                                                                                                            | A header column: start, end, `isBreak`                                                                | Time slot                                                             |
| `DictionaryEntry`                          | `DictionaryEntry`                                                                                                     | A catalogue row printed on the document: code, title, abbreviation, faculty                           | Subject catalogue entry (`SubjectCatalogue` = `Vec<DictionaryEntry>`) |
| `ResolvedSubject` / `SubjectResolution`    | `ResolvedSubject` / `enum SubjectResolution { Exact, Initialism, Near, None }` (serialised exactly as the TS strings) | The subject match and its confidence class                                                            | Subject / unresolved match (`UnresolvedMatch` = `resolution == None`) |
| `GridClass.batch`                          | `GridClass.batch: Option<String>`                                                                                     | A lab batch tag (A1, B2)                                                                              | `LabBatch` (no separate type; a string tag)                           |
| `PlacedLike` / `PositionedText`            | `PlacedLike` / `PositionedText`                                                                                       | Positioned text with page, x, y, width, height                                                        | Normalised OCR or PDF input                                           |
| `DocxStructure` / `DocxTable` / `DocxCell` | the same                                                                                                              | The DOCX table model: grid spans, vMerge, x-extents                                                   | Timetable cell (`GridCell` = `DocxCell` for DOCX)                     |
| `DocxTimetableSection`                     | the same                                                                                                              | One class section (V (A), V (B)) of a DOCX                                                            | n/a                                                                   |
| `TimetableContext`                         | the same                                                                                                              | Section, semester and academic year read from the page                                                | n/a                                                                   |
| `TimetableConflict` / `TimetableCoverage`  | the same                                                                                                              | Overlaps, and how much of the grid was resolved                                                       | Abstention and confidence                                             |
| `PeriodGrid` / `PeriodClass`               | the same                                                                                                              | The period-numbered grid variant                                                                      | n/a                                                                   |
| `Weekday`                                  | `enum Weekday { Mon, Tue, Wed, Thu, Fri, Sat }` (serialised as "Mon"…)                                                | A day                                                                                                 | Day                                                                   |
| `OcrWord` / `OcrPageResult`                | `OcrWord` / `OcrPageResult`; the new boundary type is `OcrPage { regions: Vec<OcrRegion> }`                           | Engine output                                                                                         | OCR text and coordinates                                              |

Not used, to avoid confusion: "Timetable" for the stored `SavedTimetable`. A stored timetable keeps its TS name, `SavedTimetable`, and stays in TS.
