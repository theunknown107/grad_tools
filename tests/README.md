# tests/

Cross-cutting test suites that span packages: end-to-end (Playwright), accessibility
(axe-core) and API contract tests.

**Empty by design.** Unit and integration tests live beside the code they test — see
`packages/academic-rules/test/`. This directory fills once there is a web app and an API
to exercise (backlog items M2.2, M2.3, M2.18). See `docs/33_M2_IMPLEMENTATION_BACKLOG.md`.
